One alien tourist, one star for Earth, five stars for the food. A single
sentence: an outsider's baffled grievance about this planet — paying rent
to breathe, queuing behind a goose for a parking permit — that still lands
a real compliment about the noodles, good enough to apply for citizenship.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` (one sentence, at most 200
characters) and exits 0.
